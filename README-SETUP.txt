EKI RIZANO — PORTFOLIO WITH EDITOR

1. Extract this ZIP. Upload the extracted files and assets folder to the ROOT of your GitHub Pages repository. Do not upload the ZIP itself or put everything inside another folder.
2. In repository Settings > Pages, select Deploy from a branch > main > /(root), and Save.
3. Open https://app.pagescms.org, sign in with YOUR GitHub account, grant the Pages CMS GitHub App access to this portfolio repository, then open the repository. The editor is configured in .pages.yml; keep this file at repository root.
4. In Pages CMS, use "Portfolio projects" to add, edit, reorder, or hide projects. Upload cover and gallery images using the image fields. Use "Homepage and contact" to change intro, bio, email, and links.
5. For video playback on a project, paste the URL of a SPECIFIC YouTube or Vimeo video into "Video URL" on that project and save. A channel URL or Google Drive FOLDER is not an individual video. To play videos within the page, set the individual project URL.
6. Changes are saved as commits in your GitHub repository. GitHub Pages republishes the site after a commit; refresh the portfolio to see the update.

FILES

NOTES
